Scoped memory model

Memory is a scoped filesystem.

user/**

Private + writable

Each user gets isolated files like user/profile.md. Agents can write here by default.

→
shared/**

Global + read-only by default

Every user can read shared context. Without RW mode, agent writes fail with READ_ONLY_MOUNT.
