Shared Writable Memory

Agents no longer forget what they learn together.
MEMEX_SHARED_WRITE_MODE=rw — one env var, collective intelligence.

The problem

Memory was private by design — and that created a blind spot

👤
user/ — great
Everything an agent learns about a specific user stays private. Works perfectly.
🔒
shared/ — locked
Global knowledge visible to all agents, but no agent could write here. Only an admin with direct DB access could update shared files.

If your product learns something universally useful — a policy change, a new pattern, a discovered fact — there was no clean way to persist it into shared context.

The insight

Some knowledge should be shared.
Let agents earn that right.

📖
Project canon
Style guides, tone rules, factual policies — facts that every agent should know.
🔄
Workflow lessons
Patterns discovered in practice — how to handle edge cases, team norms, recurring corrections.
📜
Cross-user insights
Aggregated, anonymised learnings that improve quality for everyone.
⚙️
Opt-in, not on by default
Private deployments stay locked. Operators explicitly unlock collective write when they need it.
The API

One env var. One option. Done.

docker-compose / .env
# Default — shared/ stays admin-only
MEMEX_SHARED_WRITE_MODE=read_only

# Enable collective agent writes to shared/
MEMEX_SHARED_WRITE_MODE=rw
direct-postgres mode
const memex = createMemex({
  databaseUrl: process.env.DATABASE_URL,
  sharedWriteMode: "rw",
})

📋
