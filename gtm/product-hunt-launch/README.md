# MemexAI Product Hunt Launch Plan

This folder consolidates the public launch story, Product Hunt materials, image concepts, video scripts, outreach sequences, and review notes for a MemexAI Product Hunt launch.

## Launch Thesis

MemexAI should launch as **the memory loop that changes an agent's next response**: durable user memory is stored in Postgres, injected back into the next model call, and backed by human-readable files, revisions, access logs, scoped paths, admin UI, MCP, SDKs, and optional background consolidation through Dreaming.

The strongest Product Hunt hook is not "another memory SDK." It is:

> AI memory is only valuable when it changes the next answer, and your team can inspect why.

## Primary Goal

Drive qualified attention from builders of AI products who are already feeling the pain of long-running memory: support agents, copilots, personal assistants, vertical AI workflows, customer-facing AI apps, and internal agent tooling.

## Product Hunt Constraints To Respect

Product Hunt's current launch guide says: tagline max 60 characters; description max 500 characters; thumbnail should be square, recommended 240x240 and under 3MB; gallery requires at least two images and recommends 1270x760; video is optional but only YouTube links are supported; first maker comment is highly visible and should introduce the team, product, target users, story, and feedback ask.

Source: Product Hunt launch guide, "Preparing for launch", https://www.producthunt.com/launch/preparing-for-launch

## Launch Stance

Be concrete, technical, and calm. Product Hunt punishes vague "AI that remembers everything" copy because the market has seen too many memory claims. MemexAI wins by showing the full loop:

- Store a durable memory.
- Inject the MemexAI prompt block into the next model call.
- Verify the next answer uses the memory.
- Open the file, revision, and access log that explain why.
- Revisions and access logs by default.
- Scoped user and shared memory.
- Admin UI for humans.
- Dreaming for memory hygiene, not magical self-improvement.
