**Priority:** P2

**Status:** [x] done

## Narrative
MemexAI is a Git-repo-shaped system of record for agent memory: files are readable, changes have revisions, access leaves logs, and humans can review or correct the durable state that changes future answers.

The point is not that MemexAI literally replaces Git. The point is that agent memory should feel inspectable and reviewable in the same way engineering teams expect code and config to be inspectable and reviewable.

## Launch Copy
- "If memory changes the answer, your team should be able to open the file."
- "Treat memory like product data, not model fog."
- "Durable memory deserves a review trail."
