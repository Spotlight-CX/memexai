# Add Indie Hacker Outreach Segment
**Priority:** P3
**Type:** gtm-content
**Status:** [x] done

## Segment
Indie hackers building AI products with returning users: coaching apps, support copilots, personal CRMs, education tools, real-estate assistants, and productivity agents.

## Pain
Users churn when the AI forgets preferences, goals, and corrections. Founders can hack prompts for a demo, but they need a simple inspectable memory loop once real users return.

## Outreach Angle
"If your AI app has returning users, try the 90-second proof: Docker up, write one user preference, inspect it, and ask a follow-up that changes because the memory exists."

## Channels
- Product Hunt maker replies
- Indie Hackers launch post
- Founder Slack/Discord communities
- Direct replies to builders posting "my AI app forgets users" demos
