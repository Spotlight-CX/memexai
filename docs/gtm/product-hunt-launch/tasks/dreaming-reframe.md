# Promote Dreaming to Pillar 2-3 in Storylines and Gallery
**Priority:** P2
**Type:** copy-update
**Status:** [x] done

## What Changed
Dreaming is now treated as a launch pillar, not a buried advanced feature. The story is:

1. Agents write durable memory during the session.
2. Prompt blocks make that memory available to the next answer.
3. Dreaming attempts to clean and consolidate memory after the session goes quiet.

## Copy Bank
- "Memory that only grows is another log. Memory that dreams can stay useful."
- "The agent writes during the session. Dreaming cleans up after the session goes quiet."
- "Dreaming can keep inspectable memory readable without hiding the revision trail."
